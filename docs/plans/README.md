# Plans Directory

This directory contains planning documents by level:

- `roadmap.md`
  - Strategic direction and long-horizon product intent.
- `execution-plan.md`
  - Active cycle implementation phases and delivery commitments.
- `backlog.md`
  - Incoming work not yet committed into execution phases.
- `archive/`
  - Closed-cycle snapshots for historical traceability.

## Working Flow

1. Capture new work in `backlog.md`.
2. Prioritize and select items for the current cycle.
3. Move selected items into `execution-plan.md` with owner and target.
4. When cycle closes, snapshot `backlog.md` and `execution-plan.md` into `archive/`, then reset active files.
